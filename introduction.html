1 Introduction

This document compiles useful approaches, tips, and tricks for using R with archaeological data. Example data used are from Drennan (2009) unless otherwise specified. This is a smorgasbord, not an introduction to analytical methods. For data manipulation, see Data Wrangling for Archaeology.
